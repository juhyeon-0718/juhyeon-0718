  - Claude AI 연동 — 상담일지 초안 자동 생성 · 성적 분석 리포트
  - 출결 세션 관리 · 카카오페이 수납 연동 · 단어장 퀴즈
  - Google/Kakao OAuth2 소셜 로그인 + JWT Refresh Token 자동 갱신
  - kakao pay 단일 결제 기능 구현
